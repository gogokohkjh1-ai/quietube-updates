# QuietTube Windows 배포

Windows 10/11 x64용 QuietTube 배포 파일과 서명된 업데이트 정보입니다.
앱 내부에서 YouTube를 실행하며 별도 브라우저나 광고 차단 확장 설치가 필요하지 않습니다.

Releases에서 ZIP을 받아 전체 압축을 풀고 QuietTube.exe를 실행합니다.
사용설명서와 오픈소스 라이선스는 ZIP에 함께 있습니다.
최신 버전 확인·다운로드는 공개 배포 채널이 게시된 후 사용할 수 있습니다.
서명과 파일 검증을 거친 업데이트는 다시 시작할 때 적용됩니다.

Google·YouTube 공식 앱이 아니며 광고 제거와 로그인 호환성을 보장하지 않습니다.
실제 계정 로그인·2단계 인증·패스키와 장시간 사용은 배포자 직접 시험 범위에서 제외되었습니다.
개인키·인증정보·사용자 프로필·원본 소스 저장소는 이 배포 저장소에 포함하지 않습니다.
